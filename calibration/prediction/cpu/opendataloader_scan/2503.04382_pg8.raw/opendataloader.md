We recall [43, Def. 4.46] that a spacetime is future distinguishing if I + ( p ) = I + ( q ) ⇒ p = q (and similarly in the past case). A spacetime is weakly distinguishing if I + ( p ) = I + ( q ) and I − ( p ) = I − ( q ) ⇒ p = q , cf. [43, Def. 4.47]. A spacetime is distinguishing if I + ( p ) = I + ( q ) or I − ( p ) = I − ( q ) ⇒ p = q , cf. [43, Def. 4.59].

Definition 2.2. We say that the the Lorentzian distance future distinguishes events (the spacetime is future d -distinguishing) if d p = d q ⇒ p = q , and that is past distinguishes events if d p = d q ⇒ p = q . The spacetime is d distinguishing if it is both future and past d -distinguishing, namely: d p = d q or d p = d q ⇒ p = q . We say that the spacetime is weakly d -distinguishing if d p = d q and d p = d q ⇒ p = q .

Note that d -distinction implies ‘future or past d -distinction’ which implies weak d -distinction.

Remark 2.3 . Weak d -distinction is called just d -distinction (or it is said that the Lorentzian distance distinguishes events) in [45, 13] as this is the only version that plays a role in those works.
