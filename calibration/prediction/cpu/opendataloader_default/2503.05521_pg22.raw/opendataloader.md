The generalized Lorentzian cone w.r.t. −I, the metric space F and the function f : I → (0,∞) is

(I × F,D,≪,≤,τ) =: −I ×f F.

If F is an intrinsic metric space, then −I ×f F is a Lorentzian pre-length space in the sense of [KS18].

Here we collect some properties of −I ×f F. We always assume that F is intrinsic.

- • −I ×f F has the push-up property: if (s,x) ≪ (t,y) if and only if there exists a future directed causal curve from (s,x) to (t,y) with positive length. Moreover I+/−((s,x)) is open for all (s,t) ∈ I × F.
- • If F is geodesic, then J±((s,x)) is closed for all (s,x) ∈ I × F.
