# Statistical methods

We transformed the variables S and AE to common logarithms. Then we performed univariate and bivariate linear regressions and calculated the usual statistics: intercepts, coefficients, probabilities, and R2-values. We excluded Hawaii from the regression analyses for Amphibia and Reptilia because these classes are not found in that zoological region.
