II. PROBLEM FORMULATION

In this section, we formulate the CSPD as an optimization problem which balances the WSR performance and the smoothness of the effective channels.

A. System Model

We consider a single-cell massive multiple-input multipleoutput (MIMO) system consists of a BS equipped with a uniform planar array (UPA) comprising M = MzMx antennas, where Mx and Mz denote the number of horizontal and vertical antennas, respectively. The BS serves K singleantenna users. Orthogonal frequency division multiplexing (OFDM) modulation is employed. The number of subcarriers is Nc, and Nv subcarriers are allocated for data transmission. Each time slot contains Nb OFDM symbols, and the channel parameters remain constant within each OFDM symbol but vary across different symbols.
