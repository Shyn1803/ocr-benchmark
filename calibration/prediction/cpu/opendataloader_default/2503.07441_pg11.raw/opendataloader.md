A Hamiltonian connection A on [0,1] × M uniquely corresponds to a choice of a smooth function H : [0,1] × M → R, normalized to have mean zero at each moment. For the holonomy path of A over [0,1] is a path ϕA : [0,1] → Ham(M,ω), generated by a Hamiltonian H : [0,1] × M → R, and this uniquely determines the connection. Conversely, H uniquely determines a Hamiltonian connection with holonomy path generated by H. We can say that H generates A.
